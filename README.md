Entry for the make.fun bounty [Sum up 24 November's world news in one image](https://make.fun/bounty/news-image-20261124).

A newspaper front page summing up Tuesday, 24 November 2026 in one image
(`entry.png`, 1024×1024): the overnight Russian strike on Zaporizhzhia, the
Israeli strike that killed Hamas security chief Naeem Abu Nahel in Gaza,
Sanofi's $41bn deal for Insmed, the Solomon Islands ending its China security
pact, the 5.6 earthquake in Nepal, Pakistan's astronaut heading for China's
Tiangong station, and Kyiv defending its strike on Russian ships off Libya.

The image was drawn programmatically (Python + PIL, system fonts) so every
headline and summary is crisp, legible text. `main.ts` (Node 22) simply copies
`entry.png` to `/output/entry.png`.
